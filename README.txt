SAGNAT — SITIO WEB EDUCATIVO
================================

ARCHIVOS
- index.html: estructura y contenido.
- css/style.css: diseño, colores y animaciones.
- js/script.js: menú, simulador y checklist.
- manifest.json: configuración de aplicación web.
- service-worker.js: caché básica para uso sin conexión.
- assets/paw.svg: icono.

CÓMO ABRIR
1. Descomprime la carpeta conservando su estructura.
2. Abre index.html en un navegador.
3. Para probar la instalación PWA y el modo sin conexión, sirve la carpeta desde localhost o HTTPS.

NOTA: El simulador es visual y no controla una placa Arduino real. Confirma los componentes exactos de tu prototipo con el video de referencia.
